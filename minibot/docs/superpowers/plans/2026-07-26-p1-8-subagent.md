# P1-8 · Subagent (Plan)

> spec：`specs/2026-07-26-p1-8-subagent-design.md`  
> 依赖：P0-1 审批、P0-3 SQLite、P0-4 SSE、P0-6 provider

## Constraints

- 子 agent 不落 messages 表；只可选择性落 `subagent_runs` 表
- 并行数默认上限 4，避免爆连接
- Loop 最大迭代数继承父 config
