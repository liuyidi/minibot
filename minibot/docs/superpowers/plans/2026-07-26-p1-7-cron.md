# P1-7 · Cron / 定时任务 (Plan)

> spec：`specs/2026-07-26-p1-7-cron-design.md`  
> 依赖：P0-1 审批（headless 拒绝）、P0-3 SQLite、P0-4 SSE

## Constraints

- 不引入 apscheduler；用 `croniter` + 自写 loop（apscheduler 太重且难与 asyncio 干净配合）
- 补跑严格 at-most-once
- prompt 模板变量固定：`{now}`, `{task_title}`；不支持任意变量
